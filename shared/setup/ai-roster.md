## The rule that makes this work

**No two of them can talk to each other.** There is no AI-to-AI channel and
there will not be one. Isaac is the bridge, every time.

That is not a flaw in the setup — it is the setup. What breaks is forgetting
it: assuming an idea told to one is known by the others. That is exactly how
"Tyson's Picks" got reinvented as a brand-new idea when it already existed.

**The protocol:**

1. Work the problem with whichever assistant fits it
2. Bring the *conclusion* back — paste it, don't summarize from memory
3. It gets written into **Ike OS**
4. Every assistant starts the next session from the same page

Step 3 is the only one that matters. Skip it and the work evaporates.

## Why "least cluttered" is the wrong selection criterion

Isaac chose Flex partly because it had the fewest projects and least clutter.
Reasonable instinct, wrong layer.

Clutter is not a property of any one assistant. It comes from work landing in
four heads that never sync. Move to the clean one and in a few weeks it is the
cluttered one and you are shopping for a fifth.

**The genuinely clean head is Notion.** It does not forget, does not fill up,
and does not need re-explaining. Route conclusions there and all four start
clean every time.
