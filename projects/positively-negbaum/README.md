# Positively Negbaum — Book #1 (Wesley Negbaum, the Misunderstood Manatee)

**What this is:** Isaac's children's picture-book franchise. Book #1 of a planned series
(Negative Nancy, Negative Nelly, the Yeah-Yeahs, Barry the Bitter Barracuda, Crabby the Crab,
Katya "Got Ya" Catfish, Lenny the Leech — each seeded as background cameos in Book #1).

**Core moral:** "Your choices shape your fate, not your name." / "You can't choose every
thought that swims by, but you choose which thoughts you feed."

**Locked canon (Book #1):**
- Wesley comes from a long line of negative Negbaum manatees.
- The real root problem is inherited negative self-talk (the "old Negbaum echo").
- Marcus A. Whaleus tries first; Wesley can't hear him yet.
- Happy the Clam helps Wesley get quiet (Happy Place / Clampdown Protocol) so he CAN hear Marcus.
- Wesley reclaims the name — becomes "Positively Negbaum," opens Negbaum's shop
  ("Neg Be Gone with Negbaum's!").
- Happy's shell seeded as both strength and limitation (future arc).
- Sourpusses' game "Who's Got It Worse?" is flipped to "Good, Better, Best."
